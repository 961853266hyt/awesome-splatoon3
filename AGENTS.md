# Repository Guide

This repository is an awesome list for Splatoon 3 resources.

## Conventions

- Keep `README.md` and `CONTRIBUTING.md` as the English sources.
- Keep `README.zh-CN.md` and `CONTRIBUTING.zh-CN.md` as the Simplified Chinese mirrors.
- Keep resource names, URLs, category order, and item order aligned across both README files.
- Add new resources under the best matching section in `Unofficial Links`; create a new subsection only when needed.
- Update `Contents` whenever sections change.
- Keep descriptions short, neutral, and useful.
- Avoid duplicate links because `awesome-lint` checks for them.

## Skills

- Use `skills/add-awesome-resource/SKILL.md` when adding, categorizing, or updating a resource.
