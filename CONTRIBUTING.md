# Contributing

[English](CONTRIBUTING.md) | [简体中文](CONTRIBUTING.zh-CN.md)

Thanks for helping improve Awesome Splatoon 3.

## New to Pull Requests?

- If you have a GitHub account but are not familiar with pull requests, read GitHub's [Contributing to open source](https://docs.github.com/get-started/exploring-projects-on-github/contributing-to-open-source) guide first.
- If you do not have a GitHub account, email your resource suggestion to <huyiteng4@gmail.com> using this format:

  ```text
  Subject: awesome splatoon3
  Body: [Name](https://example.com) - Short explanation of why this is useful.
  ```

## Pull Request Guidelines

- Add one resource per pull request when possible.
- Place the resource in the most relevant section.
- Use this format:

  ```md
  - [Name](https://example.com) - Short explanation of why this is useful.
  ```

- Keep descriptions concise, factual, and consistent with nearby entries.
- Avoid duplicates, dead links, referral links, and low-quality link collections.
- Keep `README.md` and `README.zh-CN.md` synchronized when adding, removing, or reorganizing resources.
