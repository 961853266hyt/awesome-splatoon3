## Enlaces No Oficiales

### Wiki

- [Inkipedia: Splatoon 3](https://splatoonwiki.org/wiki/Splatoon_3) - Referencia wiki de la comunidad para mecánicas, armas, equipo, etapas, modos y actualizaciones.
- [Ikanimo | 斯普拉遁中文资料站](https://splatoon.com.cn/pages/1) - Sitio de información, guías y datos de Splatoon 3 en chino.
- [Splatoon3 - スプラトゥーン3 攻略＆検証 Wiki](https://wikiwiki.jp/splatoon3mix/) - Wiki no oficial japonesa para guías de estrategia y verificación de mecánicas de Splatoon 3.
- [Splatoon Lore Ink.](https://splatoonlore.ink) - Archivo del mundo, la historia y el lore de los personajes de Splatoon con traducciones de entrevistas, libros de arte y medios del juego.
- [Sunken Scrolls](https://sunkenscrolls.ink) - Archivo y directorio de recursos de Splatoon, incluyendo guías, sitios, herramientas, assets y enlaces de la comunidad.

### Herramientas

- [sendou.ink](https://sendou.ink/) - Centro competitivo de Splatoon con torneos diarios, ladder estacional, herramientas y builds de los mejores jugadores.
- [Inksight](https://hana.lol/inksight/) - Analizador de repeticiones de Splatoon 3 para revisar datos de partidas, banderas de anticheat y estadísticas de jugadores.
- [splatoon3.ink](https://splatoon3.ink/) - Recurso web para horarios actuales, rotaciones, datos de Salmon Run, equipo y datos del juego.
- [Splatoon 3 Calendars](https://shiky.me/splatoon3) - Generador de feed de calendario para horarios de batallas, Salmon Run y eventos especiales de Splatoon 3.
- [Splashtag Creater](https://splashtagmaker.com/) - Creador de placas de nombre de Splashtag.
- [Splatoon 3 Weapon Analyzer / MCP Server](https://splatoon.kotoar.com/mcp) - Herramienta y servidor MCP para análisis de armas, builds, horarios y datos del juego de Splatoon 3.
- [Splatoon VODs](https://splatoonvods.entre-el.top/) - Base de datos para encontrar videos de partidas de los mejores jugadores de Splatoon 3 con filtros detallados como armas y mapas.
- [stat.ink](https://stat.ink/) - Plataforma de seguimiento de resultados de batallas y estadísticas para los juegos de la serie Splatoon.

### Desarrollo

- [YoungSx/splatoon-ui](https://github.com/YoungSx/splatoon-ui) - Librería de componentes de React inspirada en Splatoon, construida sobre shadcn/ui y Radix.

### Assets

- [decipher.ink](https://decipher.ink) - Fuentes de escritura y tablas de cifrado de Splatoon, con un generador de imágenes de glifos del universo del juego.
- [Deciphering the Inkling Language](https://www.youtube.com/watch?v=TKeCXNFN7eA) - Video con una descripción que recopila recursos de fuentes y escritura del idioma Inkling.
- [Octo Expansion font recreations](https://kirbypost-generator.tumblr.com/post/181817656650/octo-expansion-font-recreations-the-haikarawalker) - Recreaciones de las fuentes de Deepsea Metro y Octo Expansion.
- [Padotagi - Splatoon2 Cursor](https://blog.naver.com/padotagi_blog/221323905612) - Pack de cursores de Splatoon 2.
- [Padotagi - Splatoon3 & Side Order Cursor](https://blog.naver.com/padotagi_blog/224313544020) - Pack de cursores de Splatoon 3 y Side Order.
- [Splatoon 3 - The Models Resource](https://models.spriters-resource.com/nintendo_switch/splatoon3/) - Assets de modelos de Splatoon 3 descargables desde The Models Resource.
- [Splatoon 3 - The Spriters Resource](https://www.spriters-resource.com/nintendo_switch/splatoon3/) - Assets de sprites y texturas de Splatoon 3 descargables desde The Spriters Resource.
- [Splatoon 2 March 2017 Pilot Build Gamerip OST](https://archive.org/details/splatoon-2-march-2017-pilot-build-gamerip-ost_202605) - Archivo de música anteriormente no lanzada de una build piloto de Splatoon 2.

### Miscelánea

- [SPLATOON PROMO KID MASTERLIST](https://docs.google.com/document/d/1by1PxDAeq7mwenH9uOM9HqVUqzlVIdF2SF8ND_mFJqw/edit?tab=t.0#heading=h.1vmxmrx9e8vz) - Lista de referencia de personajes promocionales oficiales fuera de los juegos y el manga.

### Aplicaciones

- [memesquid](https://diudiu-wl.github.io/download-memesquid/) - Una linda mascota de escritorio que te acompaña mientras ves videos.
- [Mollusk Voice Changer](https://itohyakkei.booth.pm/items/8308198) - Cambiador de voz gratuito y en tiempo real para Inkling y Octoling.
- [little squid pet](https://diudiu-wl.github.io/downloadsquid/) - Una linda mascota de escritorio con reconocimiento de victoria/derrota, integración de chat en vivo y funciones de conversación.

### Bots

- [paul-sama/splatoon3-bot](https://github.com/paul-sama/splatoon3-bot) - Bot de Splatoon 3 para buscar estadísticas de jugadores encontrados en partidas, con soporte para KOOK, Telegram y Discord.
