# Add Awesome Resource

## Workflow

1. Add the resource to the best matching section in `README.md`.
2. Use this format: `- [Name](URL) - Short description.`
3. Keep descriptions concise, neutral, and useful.
4. If a matching section does not exist, add one under `Unofficial Links` and update `Contents`.
5. Mirror the same resource in `README.zh-CN.md`.
6. Keep resource names, URLs, and order aligned across both README files.
7. Avoid duplicate links.
